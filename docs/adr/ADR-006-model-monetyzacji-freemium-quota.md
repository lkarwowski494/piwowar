# ADR-006: Model monetyzacji: Freemium Quota 3 warek + wieczysty Read-Only

*Status:* Zatwierdzony (Accepted)  
*Data:* 2026-10-18  
*Decydent:* Principal System Architect & Tech Lead  
*Powiązane wymaganie:* DEC-006  

---

## 1. Kontekst
Utrzymanie architektury zerowych kosztów stałych ($0) i budowa etycznego modelu przychodowego.

---

## 2. Rozważane Opcje
Opcja A: Twarde funkcje Pro (woda, Tilt) zablokowane od początku. Opcja B: Pierwsze 3 warki 100% Pro, potem zakup Apps4Brew Pass, z zachowaniem prawa do odczytu historii.

---

## 3. Decyzja
Opcja B (Freemium Quota 3 warek + Apps4Brew Pass).

---

## 4. Konsekwencje i Wpływ na System
Maksymalny współczynnik zachwytu produktem (Aha! moment); wysoka konwersja bez niszczenia zaufania.
