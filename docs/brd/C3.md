### `RD-16: Temperatura Wody do Zacierania (Strike Water Temperature)`
- **Formuła matematyczna:**
  $$T_{\text{strike}} = \frac{0.41}{R} \times (T_{\text{target}} - T_{\text{grain}}) + T_{\text{target}}$$
  gdzie:
  - $R$ — stosunek objętości wody do masy ziarna [L/kg] (standardowo 2.5–3.5 L/kg)
  - $T_{\text{target}}$ — docelowa temperatura pierwszej przerwy zacierania [°C] (np. 67.0°C)
  - $T_{\text{grain}}$ — temperatura suchego ześrutowanego słodu [°C] (domyślnie 20.0°C)
  - Stała $0.41$ wynika ze stosunku ciepła właściwego słodu ($c \approx 0.41\,\text{cal/g}\cdot^\circ\text{C}$) do ciepła właściwego wody ($1.0\,\text{cal/g}\cdot^\circ\text{C}$).
- **Wiarygodność:** Tier 1 (Palmer, *How to Brew* / Kunze, *Technology Brewing and Malting*).
- **Wektory testowe:** `VEC-STR-01…03`.

### `RD-17: Rozpuszczalność CO₂ i Masa Cukru do Refermentacji w Butelkach`
- **Rozpuszczony resztkowy $CO_2$ w piwie po fermentacji:**
  Dla najwyższej temperatury $T$ w °C osiągniętej po fermentacji burzliwej:
  $$CO_{2,\text{resztkowy}} [\text{vol}] = 1.013 \times \left(0.01821 \cdot T^2 - 0.0805 \cdot T + 1.705\right) \times 0.605$$
  *(uproszczony wielomian deClercka dla 1 atm)*
- **Wymagana masa sacharozy (cukier biały / trzcinowy):**
  $$m_{\text{sacharoza}} [\text{g}] = (V_{CO2,\text{target}} - CO_{2,\text{resztkowy}}) \times 4.0 \times V_{\text{piwa}} [\text{L}]$$
- **Przeliczniki surowców zamiennych:**
  - Glukoza jednowodna: $m_{\text{glukoza}} = m_{\text{sacharoza}} \times 1.09$
  - Suchy ekstrakt słodowy (DME): $m_{\text{DME}} = m_{\text{sacharoza}} \times 1.30$
  - Miód pszczeli: $m_{\text{miód}} = m_{\text{sacharoza}} \times 1.25$
- **Wiarygodność:** Tier 1 (ASBC / Daniels, *Designing Great Beers*).
- **Wektory testowe:** `VEC-PRIME-01…03`.

### `RD-18: Mineralizacja Wody Zaciernej Solami Piwowarskimi`
- Wpływ dodatku $1.0\,\text{g}$ soli na $10.0\,\text{L}$ wody czystej (RO):
  - **Gips piwowarski ($\text{CaSO}_4 \cdot 2\text{H}_2\text{O}$):** $+23.3\,\text{ppm } Ca^{2+}$, $+55.8\,\text{ppm } SO_4^{2-}$
  - **Chlorek wapnia ($\text{CaCl}_2 \cdot 2\text{H}_2\text{O}$):** $+27.2\,\text{ppm } Ca^{2+}$, $+48.3\,\text{ppm } Cl^-$
  - **Sól Epsom ($\text{MgSO}_4 \cdot 7\text{H}_2\text{O}$):** $+9.9\,\text{ppm } Mg^{2+}$, $+38.9\,\text{ppm } SO_4^{2-}$
  - **Sól kuchenna niejodowana ($\text{NaCl}$):** $+39.3\,\text{ppm } Na^+$, $+60.7\,\text{ppm } Cl^-$
  - **Soda oczyszczona ($\text{NaHCO}_3$):** $+27.4\,\text{ppm } Na^+$, $+72.6\,\text{ppm } HCO_3^-$
- **Stosunek Siarczany / Chlorki ($SO_4 / Cl$):**
  - $> 2.0$ — Akcent wytrawny, chmielowy, wyrazista krótka goryczka (IPA, APA)
  - $0.9 - 1.2$ — Profil zbalansowany (Pilsner, Amber Ale)
  - $< 0.6$ — Akcent pełny, słodowy, gładki, aksamitny (Hazy IPA, Stout, Porter)
- **Wiarygodność:** Tier 1 (Water: A Comprehensive Guide for Brewers / Palmer & Kaminski).

### `RD-19: Gęstość Zadania Komórek Drożdżowych (Pitch Rate)`
- Wymagana liczba komórek drożdżowych na warkę:
  $$N_{\text{komórek}} = V_{\text{brzeczki}} [\text{ml}] \times \text{Plato} \times P_{\text{target}}$$
  gdzie docelowy współczynnik $P_{\text{target}}$ wynosi:
  - $0.75 \times 10^6$ komórek / ml / °P — dla piw górnej fermentacji (Ale)
  - $1.50 \times 10^6$ komórek / ml / °P — dla piw dolnej fermentacji (Lager)
  - $1.00 \times 10^6$ komórek / ml / °P — dla piw mocnych (High Gravity $> 16^\circ\text{P}$)
- **Wiarygodność:** Tier 2 (White & Zainasheff, *Yeast: The Practical Guide to Beer Fermentation*).
