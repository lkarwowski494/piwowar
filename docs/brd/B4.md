# Piwowar (Brewcraft) — Tom B4: Wymagania Funkcjonalne Narzędzi — Refermentacja, Nagazowanie CO₂ i Ochrona Butelek

---

### `BR-BOT-001: Precyzyjny kalkulator cukru do refermentacji w butelkach`
- **Opis:** Obliczenie dokładnej masy surowca do butelkowania (sacharoza, glukoza jednowodna, suchy ekstrakt słodowy DME) w oparciu o objętość młodego piwa, najwyższą temperaturę po fermentacji burzliwej (rozpuszczony $CO_2$) oraz docelowy wolumen $V_{CO2}$ właściwy dla danego stylu piwa.
- **Powiązana Persona:** P1 (Początkujący), P3 (Pragmatyk).
- **Priorytet:** MUST (Bezpieczeństwo biologiczne ZP-08).
- **Etap:** MVP.
- **Kryteria Akceptacji (Gherkin):**
  - **GIVEN:** 20.0 L warki piwa pszenicznego (Weizen), najwyższa temperatura po fermentacji 20.0°C, docelowe nagazowanie $3.0\,\text{vol } CO_2$.
  - **WHEN:** Użytkownik wybiera glukozę jako surowiec refermentacyjny.
  - **THEN:** Aplikacja wylicza rozpuszczony resztkowy $CO_2$ ($0.86\,\text{vol}$), różnicę do uzyskania ($2.14\,\text{vol}$) i podaje dokładnie $186.6\,\text{g}$ glukozy (lub $9.3\,\text{g/L}$ i $4.66\,\text{g}$ na butelkę 0.5L).

### `BR-BOT-002: Twardy system ostrzegania przed „Granatami Butelkowymi” (Bottle Bomb Blocker)`
- **Opis:** Zabezpieczenie przed rozerwaniem szklanych butelek w spiżarni na skutek przedwczesnego rozlewu niedofermentowanej warki lub przekroczenia dopuszczalnego ciśnienia.
- **Powiązana Persona:** P1 (Lęk przed katastrofą domową), P4 (Senior).
- **Priorytet:** MUST.
- **Etap:** MVP.
- **Kryteria Akceptacji (Gherkin):**
  - **GIVEN:** Styl piwa wytrawny (np. Pilsner, Saison), w którym ekstrakt początkowy wynosił 12.0°P, a użytkownik próbuje zarejestrować rozlew przy gęstości końcowej FG wynoszącej 5.0°P (zamiast oczekiwanych 2.0–2.5°P).
  - **WHEN:** Użytkownik otwiera moduł butelkowania.
  - **THEN:** Aplikacja blokuje przycisk kalkulacji cukru, wyświetla czerwony migający alert: *„STOP! NIE ROZLEWAJ! Piwo nie zakończyło fermentacji (pozostało 5.0°P nieprzefermentowanych cukrów). Rozlew w tym stanie grozi natychmiastowym rozerwaniem butelek i obrażeniami ciała!”* oraz kieruje do sekcji *Doctor Wad: Uśpiona fermentacja*.
  - **WHEN:** Użytkownik planuje nagazowanie $> 3.2\,\text{vol } CO_2$.
  - **THEN:** Aplikacja wyświetla ostrzeżenie o konieczności użycia grubościennych butelek szampańskich lub belgijskich 750ml z korkiem i koszyczkiem drucianym.
