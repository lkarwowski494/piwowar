# Piwowar (Brewcraft) — Tom D4: 9-Warstwowa Strategia Testów Automatycznych

Zgodnie z **Definicją Ukończenia (DoD)** studia Apps4Craft, Piwowar podlega rygorystycznemu programowi weryfikacji jakościowej na 9 warstwach:

---

## 1. Wykaz Warstw Testowych

1. **Warstwa 1: Statyczna Kontrola Typów (Typecheck):**
   - Rygor TypeScript w trybie `strict: true` (zero typów `any`).
   - Komenda commitowa: `npm run typecheck`.
2. **Warstwa 2: Symetria Językowa i Lokalizacja (i18n):**
   - Skrypt `npm run check:i18n` weryfikujący zgodność 1:1 kluczy we wszystkich 35 słownikach JSON z plikiem wzorcowym `_source.json`.
3. **Warstwa 3: Deterministyczne Testy Matematyczne (RD Unit Tests):**
   - 100% pokrycia formuł fizykochemicznych testami jednostkowymi zasilanymi bezpośrednio plikiem `docs/brd/fixtures/test-vectors.json` (tolerancje zdefiniowane w pliku).
4. **Warstwa 4: Testy Bazy Danych i Migracji SQLite:**
   - Weryfikacja operacji CRUD, integralności kluczy obcych (`PRAGMA foreign_keys=ON;`), trybu WAL oraz poprawnego działania migracji w locie.
5. **Warstwa 5: Testy Parsowania BeerXML (XML Corpus):**
   - Zestaw 30 zróżnicowanych plików `.xml` (Brewfather, BeerSmith, Beersmith 2, Grainfather) z walidacją poprawności wyodrębniania zasypu, chmieli i parametrów.
6. **Warstwa 6: Testy Komponentów UI (React Native Testing Library):**
   - Testy renderowania kontrolek kuchennych, obsługi snackbara „Cofnij”, trybu ciemnego/jasnego i kontrastu WCAG.
7. **Warstwa 7: Testy Właściwościowe (Property-Based Testing — fast-check):**
   - Generowanie tysięcy losowych wartości gęstości (0–40°P), temperatur (-10°C do 100°C) i wag, weryfikujące odporność na błędy `NaN`, dzielenie przez zero i przepełnienia.
8. **Warstwa 8: Testy Dostępności Semantycznej (A11y Audit):**
   - Weryfikacja etykiet `accessibilityLabel`, hierarchii nagłówków i czytelności przez czytniki ekranu VoiceOver/TalkBack.
9. **Warstwa 9: Scenariusze E2E na Symulatorze (Maestro):**
   - Zautomatyzowane przejście całego przepływu: *Import BeerXML → Start Zacierania → Odliczenie Chmielenia → Rejestracja Odczytu Tilt → Zapis Notatki Degustacyjnej*.
